void quickcpplib::_xxx::unit_test::test_case_skipped ( const char * reason)
externinline

Marks the running test case as SKIPPED, giving the reason.

A case that cannot run in this configuration must say so through here. Returning quietly instead reports PASSED, because the runner counts a case as passed whenever it did not fail and was not excluded by a name filter - which is how several cases in this tree came to report green having asserted nothing, with no <skipped/> in the JUnit output either.
