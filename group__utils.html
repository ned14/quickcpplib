Detailed Description

Small, dependency free helpers which the rest of the library reaches for.

They are grouped here by what they are rather than by where they live, because several parts of the library and its tests use them: number to hex string encoding and the case conversions below, the Hamming ECC in hamming_ecc.hpp, and so on. (Three \ingroup utils elsewhere in the library used to point at a group nobody defined, which doxygen 1.9 accepted silently and doxygen 1.10 and later report as "Found non-existing group 'utils'", failing the documentation build.)

Converts a number to a hex string. Out buffer can be same as in buffer.

Note that the character range used is a 16 item table of:

0123456789abcdef

This lets one pack one byte of input into two bytes of output.

Complexity
O(N) where N is the length of the number.
Errors returnable
Throws exception if output buffer is too small for input.
